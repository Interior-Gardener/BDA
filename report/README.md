## Before submitting, fill in

1. **Guide name**: replace every `<Guide Name>` (cover pages, certificate, acknowledgement).
2. **Roll numbers**: replace `(Roll No.)` on the second cover page and the project-approval page.
3. **Dates / signatures**: certificate, approval, declaration and acknowledgement pages.
4. **End matter**: attach *Published Papers*, *Certificates* and the *Plagiarism Report* (placeholder pages are included).

Tip: the page numbers in the *Contents*, *List of Figures* and *List of Tables* were generated from the final layout. If your edits shift the pagination, update those numbers by hand.

All numbers in the report come from an actual pipeline run on the default *medium* dataset (seed 42), so re-running `python run_pipeline.py --generate` reproduces them.
